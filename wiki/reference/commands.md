# Artisan Commands

Application commands from `app/Console/Commands/` (auto-registered). Scheduling lives in `routes/console.php` (`entity-orders:rebalance` runs daily).

## `admin:create`

Create or update the admin user from environment credentials

```
admin:create
```

## `ai:sync-models`

Fetch available AI models from each configured provider and store them

```
ai:sync-models [--provider [PROVIDER]]
```

## `alignments:resequence`

Renumber meaning matches by document position (repairs display order after re-align rounds)

```
alignments:resequence <entityMatch>
```

## `alignments:resume`

Pick pending entity matches, verify them, and dispatch the self-restarting alignment pipeline. Scheduled every five minutes.

```
alignments:resume [--limit [LIMIT]] [--dry-run]
```

## `crossword:index`

Build the entity word list (unique tokens with counts) from entity sentences

```
crossword:index [--entity [ENTITY]]
```

## `crossword:link`

Link unlinked entity words to dictionary words by (language, lowercase form). Run after wiktionary:import

```
crossword:link [--entity [ENTITY]]
```

## `crossword:refresh`

Find entities with a stale word list or unlinked words and dispatch background refresh jobs. Scheduled every five minutes.

```
crossword:refresh [--entity [ENTITY]] [--limit [LIMIT]] [--dry-run]
```

## `entities:import-sentences`

Import bilingual sentence pairs and create meaning matches

```
entities:import-sentences <file> <first_entity_id> <second_entity_id>
```

## `entities:import-simulator`

Import bilingual sentence pairs for simulator text entities

```
entities:import-simulator [--file [FILE]] [--all] [--skip-existing]
```

## `entities:refresh-text-hashes`

Find entities with a stale text hash and dispatch background rehash jobs. Scheduled every five minutes.

```
entities:refresh-text-hashes [--entity [ENTITY]] [--limit [LIMIT]] [--dry-run]
```

## `entity-orders:rebalance`

Rebalance sparse order values for entity sentences and meaning matches

```
entity-orders:rebalance [--entity-id [ENTITY-ID]] [--entity-match-id [ENTITY-MATCH-ID]] [--limit [LIMIT]] [--dry-run]
```

## `entity:generate-signatures`

Generate signatures for entities that have files but no signature

```
entity:generate-signatures
```

## `wiki:sync`

Regenerate auto-generated OKF wiki concepts (reference/) from live code

```
wiki:sync [--path [PATH]]
```

## `wiki:validate`

Validate the OKF wiki bundle (conformance, links, staleness)

```
wiki:validate [--path [PATH]]
```

## `wiktionary:import`

Import a Kaikki Wiktionary JSONL dump file into the database. Translations are stored for later linking via wiktionary:link-translations

```
wiktionary:import [--lang [LANG]] [--target-lang [TARGET-LANG]] [--batch-size [BATCH-SIZE]] [--] <file>
```

## `wiktionary:import-raw`

Import selected languages from a monolithic kaikki raw-wiktextract dump (.jsonl or .jsonl.gz): extract per-language files, import each, then link translations

```
wiktionary:import-raw [--langs [LANGS]] [--target-langs [TARGET-LANGS]] [--batch-size [BATCH-SIZE]] [--fresh] [--force] [--extract-only] [--skip-extract] [--no-link] [--max-lines [MAX-LINES]] [--] <file>
```

## `wiktionary:link-translations`

Link words across languages through stored translations, stripping stress marks for matching

```
wiktionary:link-translations
```

## `words:accrue-entity-frequency`

Pull word frequency ranks toward each entity's own word ranking (2% of the current value, once per entity). Scheduled every five minutes.

```
words:accrue-entity-frequency [--entity [ENTITY]] [--grace [GRACE]] [--limit [LIMIT]]
```

## `words:canonicalize-translations`

One-off: collapse mirrored word_translations rows into one canonical row per pair and rename from_word_id/to_word_id to word_a_id/word_b_id

```
words:canonicalize-translations
```

## `words:import-frequency`

Import global frequency ranks (lower = more common) onto existing dictionary words. Never creates words. Resets entity frequency-correction markers for the language.

```
words:import-frequency [--lang [LANG]] [--delimiter [DELIMITER]] [--force-redownload] [--] [<source>]
```
